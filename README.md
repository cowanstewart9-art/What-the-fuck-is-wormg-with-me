# Master Code Repository

This repository contains the consolidated source code for the project, separated into sections.

## Sections

### 1. Android Application
The root directory contains the Android project files.
- **Features:**
    - Overlay Detection (Anti-Tapjacking)
    - Background Process Monitoring
    - Idle Usage Alerts
- **Build:** Run `./gradlew build`

### 2. Python Scripts
The `python_scripts/` directory contains standalone Python utilities.
- `tictactoe.py`: A command-line Tic-Tac-Toe game with AI.
- `pointless_code.py`: A collection of humorous, pointless functions.
- **Testing:** Run `python -m unittest python_scripts/test_tictactoe.py` from the root, or inside the directory.

## Branch
This state is maintained in the `master-code` branch.
